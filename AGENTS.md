# Software Anatomy contributor notes

- Read `SKILL.md` and the contract reference for the area being changed.
- Keep stable domain IDs and canonical snapshots as replay truth. View filtering
  must not lose earlier writes or turn local message positions into global steps.
- Timeout means an unknown remote outcome. Keep capture, refund, stock custody
  and manual review separate; bundled scenarios remain clearly simulated.
- Preserve cross-panel event/FK identities and endpoints in interactive and media
  output. Reflow before scaling; retain the destination's label-size floor.
- GIF frames share geometry and one captured theme. Keep export decoding local,
  validate trust boundaries and preserve dependency license notices.
- Run `npm test` and `npm run build`. Run `npm run test:browser` for rendering,
  playback, theme, panel or media changes; inspect affected output visually.
- Keep `node_modules/`, `dist/`, `output/`, local task records, credentials and test
  profiles out of commits. Publish the Pages build output, not the checkout.
- Update `references/agent-integration.md` and integration tests when CLI/MCP
  contracts change. GitHub Pages is static hosting, not a remote MCP server.
